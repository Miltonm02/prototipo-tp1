# TurnoFácil – Prototipo inicial

## Descripción

TurnoFácil es un proyecto académico orientado al desarrollo de un sistema de gestión de turnos para una peluquería.

Esta primera etapa corresponde al prototipo inicial, en el que se comenzó a estructurar la aplicación y a trabajar con la conexión a una base de datos MySQL.

## Tecnologías y herramientas

- Java
- MySQL
- JDBC
- Programación orientada a objetos

## Implementación

- Creación de clases para representar entidades del sistema, como clientes.
- Organización del código mediante paquetes.
- Configuración de la conexión con una base de datos MySQL.
- Pruebas iniciales de conectividad mediante JDBC.

## Objetivo del proyecto

Establecer una primera estructura para el sistema y explorar la comunicación entre una aplicación Java y una base de datos relacional.

## Tipo de proyecto

Proyecto académico colaborativo.
